# shiny-octo-umbrella
A real-time chat application built with Node.js, Express, and Socket.io.

## Features
- Real-time messaging
- System notifications (join/leave)
- Differentiates between your messages and others

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   node server.js
   ```
   *(or use `npm start` if you configure it)*

3. Open `http://localhost:3000` in multiple browser tabs to see it in action!
